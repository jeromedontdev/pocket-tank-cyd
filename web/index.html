This is NOT a save-preserving update. Factory flashing overwrites saved tanks, Wi-Fi credentials, touch calibration and aquarium collection identity. Back up your aquarium and the entire SD card first. Use this only for a new board or a deliberate reset.

Already using Pocket Tank CYD? Use Settings > Device > SD Updates with update.ptu from the release to preserve your saves instead.

  1. Open this page in desktop Chrome or Edge. Firefox, Safari and mobile browsers are not supported.
  2. Connect your CYD with a USB data cable. Close serial monitors and other programs using the board's serial port.
  3. Confirm the warning below, click Connect, then choose the board's USB serial port.
  4. Choose Install in the flashing dialog and keep the cable connected until finished.
  5. Restart if needed and complete touch calibration and first-time setup. All artwork is embedded; no SD icons are needed.
Use desktop Chrome or Edge with Web Serial support. Open the HTTPS installer page in a supported browser.

Connection trouble?

Try another data cable or USB port, and install the USB serial driver appropriate to your board if no port appears. If connecting stalls, hold BOOT, briefly press RESET, then release BOOT once flashing connects. Avoid USB hubs and keep power stable.
