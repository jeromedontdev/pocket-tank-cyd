Pocket Tank CYD

For the ESP32-2432S028 Cheap Yellow Display only (4 MB flash, 2.8-inch display). Not for other ESP32 boards. The factory installer checks the ESP32 chip family, but cannot identify your display model. The save-preserving updater additionally verifies Pocket Tank's CYD identity and layout.

Use desktop Chrome or Edge over HTTPS with a USB data cable. Close all serial monitors first. Choose one of these separate operations; a refused update never falls back to a factory install.

Existing tank: save-preserving USB update

For Pocket Tank CYD 1.0.0 or newer. Back up your aquarium and SD card first. Wake your tank before connecting. This reads the firmware's ota response, restarts to check the CYD board identity, and verifies the installed partition layout. Only the reported running app slot is replaced: ota_0 / 0x20000 or ota_1 / 0x200000. Saved tanks, Wi-Fi, calibration, OTA selection and partitions are not written.

Unknown firmware, other boards, pending slot changes, unexpected layouts and downgrades are refused. No guessed offset, full-chip erase or factory image is used. This preserves stored saves, not unsaved changes. Keep USB power connected: an interrupted active-slot write can prevent booting and require expert app-only USB recovery. The SD updater is safer if power is unreliable.

The app download is checksum-verified before connecting to the bootloader. You will confirm the detected slot before writing.

Prefer SD? Use Settings > Device > SD Updates with update.ptu from the release.

New board / deliberate reset: factory installer

Loading the published factory release...

This is NOT a save-preserving update. Factory flashing overwrites saved tanks, Wi-Fi credentials, touch calibration and aquarium collection identity. Back up your aquarium and the entire SD card first. Use this only for a new board or a deliberate reset.

Already using Pocket Tank CYD? Choose the save-preserving USB update above or use SD Updates instead. This factory option writes a merged image at 0x0, including NVS and the partition table.

  1. Open this page in desktop Chrome or Edge. Firefox, Safari and mobile browsers are not supported.
  2. Connect your CYD with a USB data cable. Close serial monitors and other programs using the board's serial port.
  3. Confirm the warning below, click Connect, then choose the board's USB serial port.
  4. Choose Install in the flashing dialog and keep the cable connected until finished.
  5. Restart if needed and complete touch calibration and first-time setup. All artwork is embedded; no SD icons are needed.
Use desktop Chrome or Edge with Web Serial support. Open the HTTPS installer page in a supported browser.

Connection trouble?

Try another data cable or USB port, and install the USB serial driver appropriate to your board if no port appears. If connecting stalls, hold BOOT, briefly press RESET, then release BOOT once flashing connects for factory installation only. The save-preserving updater must first talk to running firmware: do not start it in BOOT/download mode. Avoid USB hubs and keep power stable.

Firmware comes from the latest stable GitHub release. Its checksum is checked before this site is deployed; the USB updater also checks the downloaded app's SHA-256 and the written app's checksum. Checksums detect corruption, not authenticity: these are trusted-release downloads, not signed updates. USB flashing stays in your browser; this site does not upload your tank or credentials. The flashing component is loaded from pinned ESP Web Tools and esptool-js CDNs.
